# 文档清单与开工顺序

## 一、迁移完成后如何开工

1. 在 Codex 中以 `D:\ObsidianVaults\Education\Sherlock\English-Learning` 为工作目录新建任务。
2. 先读取 `AGENTS.md`、`README.md`、`docs/02_PROJECT_STATUS.md`，确认当前阶段。
3. 方向、教材范围、formal 分析、学习档案和 P6 讨论进入 00；课程内容进入 01；代码、部署和运维进入 02；学校练习/考试批改与校内错题库进入 03。
4. P0–P5 已完成。进入 P6 前先由 00 确认学校实际教材页段和首批课程目标，不得再执行 P0 迁移指令。

## 六、阶段交接规则

- 每一阶段先读当前状态和对应阶段执行书；
- 达到验证门后更新 `docs/02_PROJECT_STATUS.md`；
- 涉及费用、正式数据、孩子负担或范围变化时，回到 00 窗口拍板；
- 代码实现细节不要求家长做低层选择；
- 未达到验证门，不得把状态写成完成。
