# P2 听力模块迁移

> 目标：在 CloudBase PWA 中复现并验证现有听力完整流程，不改变课程事实和正式数据边界。

## 进入条件

- P1 验证门通过；
- CloudBase 仍为 test-only；
- 当前听力 CONTRACT、JSON schema、课程清单、音频 manifest 和回归测试已读取。

## 本阶段范围

- 迁移课程目录、课程进入、音频播放、五类题型、提交和订正；
- 沿用现有课程 JSON 和音频资产；
- 显示首个 formal 未完成课程附近最多 5 课，历史课程隐藏但不删除；
- 家长端 test 验收明细；
- 建立新增课程不改核心程序的内容加载机制。

## 保持不变的行为

- 推荐课是第一个 visible 且 formal 未完成的课程；
- 课程继续按稳定 ID 和顺序展示；
- test 不推进推荐课或完成状态；
- 儿童端不暴露原文、答案、考点标签或数字分数；
- 家长端可查看 score、wrong_answers、section_scores、corrections 和 question_results；
- 音频路径由 manifest/课程加载器生成，不手工拼接散落 URL。

## 实施步骤

1. 为现有听力 JSON 建立 schema 校验与兼容读取层。
2. 接入课程目录、可见性、排序、推荐和 5 课窗口规则。
3. 实现播放状态、题型渲染、答题暂存、提交确认和断网防重复提交。
4. 实现五类题型及现有播放次数限制。
5. 实现儿童端非数字化反馈与逐题订正流程。
6. 通过共享提交服务保存 test 结果；实现幂等 `result_id`。
7. 家长端呈现听力完整 test 明细。
8. 抽查当前保留课程和至少一套边界课程的音频、答案与原文对应。

## 自动验证

- 全量听力 JSON schema 校验；
- 所有 manifest 条目和音频文件存在；
- 关键音频非零、格式可解码、URL 返回成功；
- 排序、首个 formal 未完成推荐和最多 5 课显示测试；
- test 不完成课程测试；
- 重复提交幂等测试；
- 各题型计分和订正测试；
- 儿童端敏感答案不泄露测试。

## 真机验证

- iPad Safari 首次播放、连续播放和锁屏返回；
- Wi-Fi 波动后的恢复；
- 选择、提交、订正和重新进入；
- 页面文字、按钮和音频控件不重叠；
- 家长 test 提交后刷新仍可查询。

## 验证门

- 本地、构建、自动测试全部通过；
- iPad 播放和完整 test 提交流程通过；
- 课程、题量、答案、原文和音频抽查一致；
- CloudBase 仍没有 formal 记录；
- 旧 Streamlit 未受影响。

## 交付物

- 可用听力模块；
- 听力 CONTRACT 和测试报告；
- 音频/manifest 对账报告；
- iPad 验收记录；
- 更新后的状态文档。
