# P1 CloudBase 基础架构

> 目标：在现有 CloudBase 免费环境内建立相互隔离的英语 PWA 骨架，开发期只能写 test。

## 进入条件

- P0 验证门全部通过；
- 新根目录已成为有效 Git 仓库；
- 已实时确认 CloudBase 环境 ID、套餐状态和剩余额度；
- 已备份当前 24 点静态托管和资源清单。

## 本阶段范围

- 建立 React + TypeScript + Vite 的 iPad-first PWA；
- 建立共享核心、学生入口、家长认证和模块路由；
- 建立 CloudBase 静态托管、云函数、数据库和云存储命名空间；
- 实现服务端 `data_kind` 判定和最小结果写入；
- 建立开发、测试和发布脚本；
- 发布仅供家长验收的 test 版本。

## 资源隔离

```text
静态路径：/sherlock-english/
云函数：sherlock-*
数据库集合：sherlock_*
云存储前缀：sherlock-english/*
日志标签：sherlock-english
```

不得修改或覆盖 24 点的路径、函数、集合、存储、环境变量和发布版本。不得新建付费环境或开启按量付费。

## 数据与身份底线

- 普通儿童 formal 入口在本阶段保持关闭；
- test 写入仅允许已认证家长会话；
- 云函数忽略浏览器自报的 `data_kind`，依据服务端身份重判；
- 家长密码只保存哈希，不进入前端包和 Git；
- CloudBase 密钥仅在本地受控配置或云端环境变量中；
- 日志不得输出密码、讯飞密钥、录音临时地址或完整个人数据。

## 实施步骤

1. 基于现有仓库测试和内容结构确定最小目录调整，不先重构课程 schema。
2. 创建 PWA shell、路由、离线提示、更新提示和错误边界。
3. 创建 `listening`、`speaking`、`parent` 模块入口；`vocabulary` 只保留注册接口，不显示未开发页面。
4. 建立课程目录读取层、首个 formal 未完成推荐接口和通用结果头 schema。
5. 创建家长认证、test 会话、结果提交和健康检查云函数。
6. 配置数据库/存储最小权限规则和审计日志。
7. 增加单元测试、契约测试、构建检查和 CloudBase 发布清单。
8. 部署到英语独立静态路径，执行桌面与 iPad 基础访问检查。

## 验证门

- 构建、类型检查和自动测试通过；
- PWA 可安装或添加到 iPad 主屏幕；
- 页面刷新、深链接和静态资源路径正常；
- 未认证请求不能写结果；
- 家长 test 可写，数据库明确标记 `data_kind=test`；
- test 不产生儿童完成状态；
- formal 入口尚未开放；
- 24 点应用在发布前后 URL 和功能正常；
- CloudBase 没有新增付费能力。

## 交付物

- PWA 基础工程；
- CloudBase 资源及权限清单；
- 环境变量模板（不含值）；
- 测试与部署脚本；
- test 站点 URL；
- 发布和回滚说明；
- 更新后的状态文档。
