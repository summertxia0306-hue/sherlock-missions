# P3 跟读口语与讯飞迁移

> 目标：在 iPad 上完成稳定的录音、回放、讯飞评分、反馈和三星门控全流程。

## 进入条件

- P2 验证门通过；
- 已读取当前 speaking CONTRACT、录音组件、讯飞适配和门控测试；
- 讯飞应用状态、授权到期日和剩余额度已实时确认；
- 讯飞密钥已有合规的云函数环境变量保存方案。

## 本阶段范围

- 迁移现有口语课程和 6 repeat + 2 QA 结构；
- iPad 麦克风授权、录音、自动停止、试听和确认；
- 通过云函数调用科大讯飞 ISE；
- 三星门控、三次后“先过这题”和弱词反馈；
- 录音私有存储和家长受控回放；
- 保留评分供应商适配层，当前不切换腾讯 SOE。

## 锁定行为

- 三星正常通关；
- 未到三星可以重试；
- 第三次仍未到三星才出现“先过这题”；
- 评分接口失败不计入有效三次；
- 保留首读、末读、最高分、每次星级、weak_words、take_stars 和 `passed_by_safety`；
- test 不产生儿童完成状态；
- 儿童端不显示原始数字分数。

## 实施步骤

1. 建立浏览器录音状态机：授权、倒计时、录制、停止、回放、确认、重录、错误恢复。
2. 将音频统一转换或约束为讯飞支持的格式；目标为单声道、16 kHz、16 bit PCM/WAV，实际以当前接口合同为准。
3. 建立 `score-speaking` 云函数，服务端签名和调用讯飞，前端永不持有 APISecret。
4. 把讯飞原始响应转换为内部统一评分对象，并保留必要的可审计原始字段。
5. 实现星级阈值、弱词识别、重试次数和 safety pass；阈值沿用当前 CONTRACT，不自行调参。
6. 将录音写入 `sherlock-english/{env}/{data_kind}/{course_id}/{result_id}/` 私有路径。
7. 家长端通过临时授权地址回放，儿童端只在当前流程试听本次录音。
8. 增加超时、空音频、过短音频、接口失败、重复回调和网络中断测试。

## 自动验证

- 现有 `test_speaking_gate` 等回归测试全部通过；
- 第 1、2、3 次门控状态精确测试；
- 评分失败不消耗次数；
- 首读/末读/最高分与每次星级持久化；
- `passed_by_safety` 与正常通过可区分；
- test 录音和 formal 路径隔离；
- 云函数日志不泄露密钥和录音内容。

## iPad 必测

- Safari 首次麦克风授权和拒绝后恢复；
- 添加到主屏幕后录音；
- 录音、自动停止、回放、重录和确认；
- 讯飞评分速度与失败提示；
- 三次门控与“先过这题”；
- 锁屏、切后台、网络变化后的状态恢复；
- S 课程 8 题完整 test 提交后可持久化。

## 验证门

- 自动测试和真机检查通过；
- 一组 8 题 test 可从录音走到结果查询；
- 录音私有且家长可受控回放；
- 讯飞密钥不在 Git、前端包或文档；
- CloudBase 仍只接受 test。
