# 4A Starter 五个听说学习包实施计划

> 依据：`docs/superpowers/specs/2026-09-07-4a-starter-five-study-packs-design.md`
> 范围：本地内容、课程 JSON、音频资产和校验；不部署、不开放 formal

## 实施顺序

1. 新增内容契约测试，先证明 D07–D11 尚未实现。
2. 新增独立生成器，以确认版教材 p2–6 为唯一事实源。
3. 生成五门听力和五门口语源 JSON，统一为隐藏 test。
4. 生成五个 study pack、家长版答案原文、教材映射、儿童安全验证副本和 134 项音频清单。
5. 运行内容定向测试、现有 Python/Web/云函数回归、类型检查和构建。
6. 使用现有音频工具生成 94 个听力 MP3 和 40 个口语 MP3，更新正式 manifest。
7. 运行音频存在性、非空、解码、哈希、manifest、同步产物和敏感信息校验。
8. 更新本批校验报告；只提交本任务新增或修改的文件，不混入既有工作区改动。

## 停止条件

- 教材确认版资料缺失或出现未解决的模糊标记；
- 必须修改已批准教学内容或核心 formal/test 规则才能继续；
- 音频生成需要购买额度、部署或写入线上数据；
- 与现有用户改动发生无法安全隔离的冲突。
