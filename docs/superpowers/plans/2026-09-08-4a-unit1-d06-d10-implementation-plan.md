# 4A Unit 1 第6–10课实施计划

> 依据：`docs/superpowers/specs/2026-09-08-4a-unit1-d06-d10-design.md`
> 范围：本地课程内容、JSON、教材映射、家长答案原文、儿童安全副本、音频与校验；不部署、不开放 formal

## 实施顺序

1. 新增 D06–D10 内容契约测试，覆盖编号、配对、页段、题量、计分、难度、题型、C比例、儿童安全字段和138项音频计划，并先确认测试因产物缺失而失败。
2. 新增独立 Unit 1 课程生成器，沿用现有课程 schema、五类听力题型、6 repeat + 2 QA 和儿童副本版本算法。
3. 生成五门听力与五门口语活动源 JSON，初始统一为 `publication_status=test`；生成五个 study pack、教材映射、家长答案原文和儿童安全校验副本。
4. 运行内容契约和现有 Python 回归，修正题量、答案、页段和 schema 问题。
5. 使用现有音频流水线为 D06–D10 生成98个听力和40个口语 MP3，并更新两个 manifest。
6. 运行 ffmpeg 全量解码、音频路径、manifest、课程版本、敏感信息、Web、两支云函数、TypeScript 和生产构建校验。
7. 生成本批校验报告；只提交本任务文件，不纳入已有用户改动，不 push、不部署。

## 停止条件

- 确认版教材 p7–14 出现无法解决的事实冲突；
- 现有 schema 无法表达已批准课程且必须修改核心程序；
- 音频生成需要付费、生产凭据或写入线上学习数据；
- 与工作区已有用户改动发生无法隔离的冲突。
