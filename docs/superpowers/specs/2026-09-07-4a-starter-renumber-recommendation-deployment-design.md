# 4A Starter 重编号、推荐窗口与正式部署设计

## 目标

将真实新教材 Starter 五课作为 2026 秋季第一批正式课程上线，并让课程推荐从现有夏季课程自然衔接到新学期课程。

## 活动课程与历史边界

- 新教材五课由 D07–D11 依次重编号为 D01–D05。
- 听力使用 `L4A-T1-W01-D01` 至 `L4A-T1-W01-D05`；口语使用 `S4A-T1-W01-D01` 至 `S4A-T1-W01-D05`。
- `pair_id` 与 `study_pack` 使用 `4A-T1-W01-D01` 至 `4A-T1-W01-D05`。
- 旧教材 D01–D06 从单一活动课程源、manifest 当前课程条目和线上课程目录下线；旧内容仍由 Git 历史保留。
- 不删除或改写任何既有 test/formal 成绩、录音或学习档案。旧 test 结果即使使用相同课程 ID，也不计入 formal 完成状态；课程版本继续防止跨版本提交。

## 正式可见与排序

- 新 D01–D05 不再设置 `publication_status=test`，进入儿童 formal 目录。
- 新学期课程按课程顺序排在保留的 `W01D50/S01D50` 之后。
- 推荐以各模块真实 formal 完成集合为准，选择课程顺序中的首个未完成课程。
- 当前口语推荐为 `S01D50`；窗口显示 `S01D48、S01D49、S01D50、S4A-T1-W01-D01、S4A-T1-W01-D02`。
- 听力独立使用听力 formal 完成集合，不伪造或跨模块复制完成状态。

## 课程窗口与按钮

- formal 儿童端固定显示推荐课前2门、推荐课和推荐后2门；边缘不足时向另一侧补齐，总数最多5门。
- 推荐前课程依据真实 formal 完成集合显示“已完成”；推荐及其后未完成课程显示“未完成”。
- 推荐卡继续保留高亮和“推荐”徽标；其操作按钮文字改为“推荐开始”。
- 其他课程按钮仍显示“开始”。

## 生成、测试与部署

- 生成器、课程 JSON、家长材料、儿童副本、study pack、音频计划和音频路径统一改用 D01–D05。
- 删除活动树中的旧 D06，并重建两个 manifest，确保没有旧教材 D01–D06 的当前课程条目或孤立引用。
- 测试覆盖编号唯一性、教材范围、五课配对、100分计分、6 repeat + 2 QA、推荐顺序、五课窗口、推荐按钮、儿童字段隔离和正式写入边界。
- 推送经验证的提交后，部署 `sherlock-api` 与现有 CloudBase 正式静态站点；保留函数现有环境变量与 `FORMAL_ENABLED=true`。
- 线上验证 D01–D05 课程与134个音频、推荐窗口、旧 D06 下线、API健康状态和无新增学习记录。

## 非目标

- 不改变三星门控、三次后安全通过、讯飞评分标准、认证或数据治理。
- 不部署新的应用、域名或付费资源。
- 不把部署验证写成 test/formal 学习记录。
